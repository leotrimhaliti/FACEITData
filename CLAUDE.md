# Project: FACEIT Data (Expo + Web)

## Standards
- Follow ECC v1.8 standards in .claude/rules
- Priority: Web compatibility for existing Mobile components

## Tech Stack
- Framework: Expo (React Native SDK)
- Routing: Expo Router (Shared Mobile/Web)
- Icons: Lucide-react (Web) / Lucide-react-native (Mobile)
- API: FACEIT Data API

## Web Migration Goals
- Use Responsive Design (Tailwind or NativeWind)
- Abstract platform-specific logic (e.g., .web.tsx vs .native.tsx)
- Implement SEO for player profile pages
