# FACEIT Data

A React Native application built with Expo to view FACEIT player statistics and match history.

## Features

- View player stats (ELO, Matches, K/D, etc.)
- Match history with win/loss indicators
- Detailed match statistics
- Search for players

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Create a `.env` file in the root directory and add your FACEIT API key:
   ```
   EXPO_PUBLIC_FACEIT_API_KEY=your_api_key_here
   ```

3. Start the app:
   ```bash
   npx expo start
   ```

## Tech Stack

- React Native
- Expo
- Expo Router
- TypeScript
